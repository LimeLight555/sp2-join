Joining the server

Steam opens SimplePlanes 2 and joins the server. If your browser asks whether to open Steam, allow it.

Open in Steam

Nothing happened? You need Steam running and SimplePlanes 2 installed on this computer: get SimplePlanes 2 on Steam.

On a phone? SimplePlanes 2 runs on a PC. Open this link there, or find the server in the game: FLY, JOIN SERVER, then switch Regional to World Wide.

The server opens a new lobby every time it restarts, so an old link stops working: press Join now on the Discord status card again for a fresh one.
